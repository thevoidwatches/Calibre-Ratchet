Ratchet

setup

Five steps, top to bottom. Nothing here asks for administrator rights, and everything it does it tells you first. You can close this and come back: it picks up from whatever is already set.

1. Tailscale

Tailscale is the private network your phone reaches this PC over. Ratchet is never put on the open internet.

2. calibre

Ratchet talks to calibre's Content server, which has to be running: in calibre, Preferences → Sharing over the net → Start server, and tick Run server automatically when calibre starts. If you gave it user accounts, enter one here.

Each device remembers the library it last used; this is only where a new one starts.

Columns (optional)

Ratchet can show and file books by custom columns you have made in calibre. Leave any of these empty if you have no such column — nothing depends on them.

This is for sorting by when a story last got new chapters. Ratchet has to write that date down somewhere each time it fetches an update, and there are two places it can:

  • A Date column of your own. Make one in calibre (Preferences → Add your own columns, type Date) and pick it here. Nothing else about your library changes.
  • calibre's built-in Date column. No new column needed — but that column is where calibre records the day you added each book. Each time a story updates, Ratchet would replace that with the day of the update. calibre keeps no copy of the old date, so there is no getting it back.

Left at (none), nothing is written, and the "Last Updated" sort simply goes by the day each book was added.

3. Let your devices in

Ratchet listens on this PC only, where nothing outside can reach it. Tailscale is asked to hand it your tailnet's traffic on one port — a setting inside Tailscale, undone with one click here. Windows Firewall is not touched, which is why no administrator prompt appears.

4. Run Ratchet

Ratchet sits in the notification area, by the clock. Starting it when you log in means it is simply there.

6. Your tags (optional)

Stories arrive wearing whatever tags their site gave them. Three text files in the config folder say how those become your tags. Ratchet works without any of them — a story simply keeps the tags it came with. They are edited by hand, and a slip in one fails silently, so this reads them and says what looks wrong. It changes nothing.
